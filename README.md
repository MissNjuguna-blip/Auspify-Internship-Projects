Running the Projects
Each project contains its own source code and configuration files.
To run a project locally:
1. Clone this repository:
git clone https://github.com/MissNyaguna-biz/Auspify-Internship-Projects.git

2. Open the repository in Visual Studio Code
3. Navigate to the project you want to run.
4. Install the required dependencies.
5. Configure the required environment variables and database connections, where applicable.
6. Follow the project's individual setup instructions to start the application.
